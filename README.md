# Reading list
[An intermediate JS project for the Odin Project.](https://www.theodinproject.com/lessons/node-path-javascript-library) A rudimentary reading list to where a user can add her books she's reading.

## Features
* Add a book's title, author, and pages read to the reading list.
* Checkbox to mark a book finished/unfinished.
* Remove button to remove a book from the reading list.
